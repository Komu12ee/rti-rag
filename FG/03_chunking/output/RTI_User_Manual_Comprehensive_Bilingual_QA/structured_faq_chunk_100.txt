## Question: What file formats and size limit are shown on the document upload screen ?

Answer: The example screen states a maximum file size of 20 MB and shows PDF, JPEG, and JPG as allowed formats. Check the live portal for any current change before uploading.

Source: RTI User Manual, Printed page 11.

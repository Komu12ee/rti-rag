## Question: Can Indian citizens use the portal for RTI applications and first appeals?

Answer: The RTI Instruction screen states that Indian citizens can use the web portal to file RTI applications online and make payment online. It also states that a first appeal can be filed online.

Source: RTI User Manual, Printed pages 5-6.

## Question: What happens if 1 select Tes for BPL card holder status?

Answer: The manual says that BPL document details must be entered if Yes is selected. The displayed form includes the BPL document number, BPL document issue date, and BPL issuing authority. The manual states that these BPL details are mandatory to process the application further.

Source: RTI User Manual, Printed page 7

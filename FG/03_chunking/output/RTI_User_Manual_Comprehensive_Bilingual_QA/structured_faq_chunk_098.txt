## Question: What kinds of supporting documents can be selected on the displayed document page?

Answer: The example upload screen shows areas for an RTI supporting document, an offline PIO answer document, a first appeal supporting document, an offline FAO answer document and an optional supporting document for the second appeal application.

Source: RTI User Manual, Printed page 11.

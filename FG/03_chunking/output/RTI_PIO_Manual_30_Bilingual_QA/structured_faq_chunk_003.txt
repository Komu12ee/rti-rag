## Question (English): Why do [ need to register before using the portal?

Answer (English): The registration instructions state that a user must be registered to apply through the portal. A valid and active email ID is mandatory because the portal sends a verification link to that address. The registered email later becomes the login ID used to activate the account and access the portal.

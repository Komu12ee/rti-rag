## Typical contexts

- Information sought is already part of mandatory suo motu disclosure published manual
- Determining whether refusal can be justified when information should already be publicly available
- Validating whether public authority has fulfilled proactive disclosure obligations

PIO implementation note: Before processing as a fresh RTI request, check whether the information is already covered under the public authority's Section 4(1 )b) suo motu disclosure manual website if so, the PIO response should direct the applicant to that published source.

## Answer

English definition: Every State Government shall constitute a State Information Commission consisting of a State Chief Information Commissioner and such number of State Information Commissioners (not exceeding 10) as determined by the State Government.

हिंदी परिभाषाः प्रत्येक राज्य सरकार राज्य मुख्य सूचना आयुक्त और राज्य सरकार द्वारा निर्धारित (दस से अनधिक) राज्य सूचना आयुक्तों से युक्त राज्य सूचना आयोग गठित करेगी|

Retrieval anchors: Composition; संरचना; SIC; State Chief Information Commissioner; State Information Commissioners; state level appeals

## Typical contexts

- Query concerns the second-appeal forum for a STATE public authority (as opposed to central)

PIO implementation note: When a PIO belongs to a state public authority the correct second appeal forum to cite in the rejection notice is the State Information Commission, not the CIC.

- Validating jurisdiction split between CIC and SIC

Source reference: RTI Rule Book, p. 15, Section 15 (multiple references throughout)

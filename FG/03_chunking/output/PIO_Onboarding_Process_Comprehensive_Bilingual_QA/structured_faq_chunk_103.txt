## Q53 (English ). What is the difference between PIO order file and signed application file?

Answer. The PIO order file is the PIO appointment order. The signed application file is the printed application signed by the PIO, Nodal Approval Authority and First Appellate Officer, then scanned and uploaded as PDF.

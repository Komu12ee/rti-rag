## Q65. What sequence should be followed for a standard different-email transfer?

Answer: Follow this sequence: Give Charge -> select different email ID -> select the relevant charge(s) > enter receiving officer details -> Submit -> receiving officer opens Take Charge -> Proceed -> selects and submits approval > check transfer status -> Generate Relieving Letter -> Print Relieving Letter -> Browse and Upload the file -> review the transfer certificate.

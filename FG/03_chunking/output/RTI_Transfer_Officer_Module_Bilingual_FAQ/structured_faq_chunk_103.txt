## Q56. Where is the name change order file uploaded?

प्रश्न 56. नाम परिवर्तन आदेश की फाइल कहाँ अपलोड की जाती है?

उत्तरः उपयोगकर्ता को स्थानांतरण की स्थिति वाले भाग में जाने का निर्देश देता हैI सूची में संबंधित अनुरोध के "Upload File for Name Change " विकल्प चुनें और आदेश फाइल अपलोड करें | मैनुअल लिए अनुरोध

Source reference : Manual pp . 9-12

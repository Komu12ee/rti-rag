## Untitled section

Q114. Can a single user file multiple Second Appeal applications?

Multiple-application policy is not explicitly specified.
The dashboard displays a Second Appeal Application Count and uses application-status counts, which is
consistent with the portal tracking multiple matters. However, the manual does not expressly state that a single
account may file multiple applications or identify any numerical limit.

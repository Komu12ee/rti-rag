## Question: Can an applicant file an RTI application and make payment online according to the instruction screen?

Answer: Yes. The RTI Application Instruction shown in the manual says that Indian citizens can use the web portal to file an RTI application online and to make payment for an RTI application online It also says that a First Appeal can be filed online. The manual then demonstrates a Second Appeal workflow connected with an offline RTI process.

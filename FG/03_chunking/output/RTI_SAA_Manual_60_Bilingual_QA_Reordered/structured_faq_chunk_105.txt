## Question: Which fields are filled in the First Appeal Application screen?

Answer: The First Appeal Application screen asks the user to select First Appeal Reason Type, enter First Appeal details, enter the offline First Appeal application date and choose Application Status. The manual then instructs the user to click Save & Next.

## Question: What should I do if the file has not changed to 'Uploaded ?

Answerः The manual treats the green Uploaded state as the indication of successful upload. If the button has not changed, do not assume the file is attached. Recheck the selected file and upload action. The manual does not provide a technical troubleshooting procedure, so consult the current portal's help or support route if the issue continues.
